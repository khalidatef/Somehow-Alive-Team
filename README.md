# Outpost 07 — Play prototype

بروتوتايب مستقل بــ React وVite. لعبة Godot المرسلة في `Build.zip` متوصلة بصفحة Play بالفعل.
صفحات The Mission وSources وEducators موجودة في التنقل وفاضية عمدًا.
المشروع بيفتح على Play تلقائيًا، وممكن تدخل عليها من `/#play`.

## التشغيل

```sh
npm install
npm run dev
```

افتح العنوان اللي Vite بيطبعه في التيرمنال، وبعده `/#play`.
الاعتماديات متثبتة بالفعل في الفولدر الحالي، فمش محتاج تعيد `npm install` دلوقتي.

```sh
npm run build
npm run preview
```

التصميم فيه عربي وإنجليزي، وضع فاتح وداكن، وملء الشاشة. الاختيارات بتتحفظ محليًا.
لو المتصفح مش بيدعم ملء الشاشة، مساحة اللعب بتتوسع داخل الصفحة وبتتقفل بـ Escape.

## الربط اللي اتنفذ — خطوة بخطوة

1. اتفك `Build.zip` واتنسخت **محتويات** مجلد `Build` داخل `public/game/`.
   الملفات الـ 12 اتنسخت كما هي، بنفس الأسماء والمحتوى، من غير تعديل كود اللعبة.
2. اتجربت صفحة اللعبة لوحدها من عنوان السيرفر متبوعًا بـ `/game/Iah-1.html`.
3. اتحدد رابط البداية في `src/pages/play/gameConfig.js`:

   ```js
   export const GAME_URL = `${import.meta.env.BASE_URL}game/Iah-1.html`;
   ```

4. القيمة دي بتفعّل زر **Start the game**. ضغط الزر بيغيّر حالة `playing` في React
   ويعرض `iframe` يشغّل صفحة اللعبة.
5. صفحة `Iah-1.html` بتحمّل `Iah-1.js`، وبعدها المحرك بيحمّل `Iah-1.wasm`
   وحزمة محتوى اللعبة `Iah-1.pck` وباقي الملفات، ويبدأ اللعب.
6. زر **Back to mission** بيشيل iframe ويرجّع شاشة البداية. ده بيوقف النسخة الحالية؛
   التشغيل من جديد ينشئ نسخة جديدة، ومش زر pause/resume.
7. `npm run build` بيضم ملفات `public/game/` في `dist/game/` تلقائيًا للنشر.
   ملفات اللعبة المُصدّرة مستثناة من ESLint؛ بنفحص كود React بتاعنا من غير تعديل
   JavaScript المُولَّد بواسطة Godot.

المسار على الديسك `public/game/Iah-1.html` بيتقدم للمتصفح باسم `/game/Iah-1.html`؛
كلمة `public` مش جزء من الرابط. `BASE_URL` بيحافظ على مسار النشر الأساسي المحدد في Vite.

## طريقة التجربة

- شغّل `npm run dev` وافتح العنوان اللي ظهر، وبعده `/#play`.
- اضغط **Start the game** واستنى تحميل اللعبة.
- اضغط داخل اللعبة قبل التحكم بالكيبورد.
- جرّب الحركة، وملء الشاشة، والرجوع لشاشة البداية.
- **Open game** بيفتح اللعبة لوحدها في تبويب تاني، وده مفيد لعزل أي مشكلة في اللعبة
  عن مشكلة عرضها داخل الموقع.

تم التحقق محليًا في Chrome من تشغيل اللعبة مباشرة وداخل Play، وتحريك اللاعب
بالكيبورد، وملء الشاشة والخروج منه، والرجوع لشاشة البداية.
الصوت والتحكم باللمس والتشغيل على أجهزة تانية لسه محتاجين تجربة منفصلة.

## حدود الربط الحالي

- ده تشغيل للعبة داخل الموقع. مفيش ربط للنتائج أو المراحل أو الحسابات بــ React أو Backend.
- اختيار اللغة والثيم بيغيّر واجهة الموقع؛ مش إعدادات اللعبة الداخلية.
- `iframe onLoad` معناه إن صفحة اللعبة اتحمّلت، مش إن محرك Godot خلّص تجهيز اللعبة.
  شاشة التحميل داخل اللعبة مسؤولة عن تجهيز المحرك وملفاته.
- النسخة الحالية إعدادها `GODOT_THREADS_ENABLED = false`، واشتغلت محليًا من غير إضافة
  COOP/COEP headers. عند النشر نراجع HTTPS ونوع ملف `.wasm` وهو `application/wasm`.
- الحجم الإجمالي للملفات بعد فك الضغط حوالي 44 MB؛ وقت التحميل على الإنترنت بيتأثر
  بالاتصال والضغط والكاش. الاستضافة النهائية لم يتم نشرها أو اختبارها بعد.

## تحديث اللعبة لاحقًا

انسخ النسخة الجديدة كاملة إلى `public/game/`، مع الحفاظ على ملفات التصدير مع بعض.
لو اسم صفحة البداية اتغير، عدّل `GAME_URL`، وبعدها جرّب التشغيل المباشر والتشغيل داخل Play.
يفضل عدم تغيير أسماء ملفات Godot يدويًا؛ ملف HTML والـ loader بيشيروا للأسماء المصدّرة.

## الملفات الرئيسية

- `src/components/Header.jsx`: الـ navbar وروابط الصفحات.
- `src/pages/play/PlayPage.jsx`: صفحة Play ومساحة تشغيل اللعبة.
- `src/pages/play/gameConfig.js`: رابط صفحة البداية للعبة.
- `public/game/`: نسخة Godot الكاملة من `Build.zip`.
- `src/copy.js`: النصوص العربية والإنجليزية.
- `src/index.css`: التصميم والمقاسات المختلفة.
- `public/assets/station.svg`: رسمة المحطة المستخرجة من مرجع HTML المرفق.

لم تُضف مكتبات npm، ولا يوجد سيرفر خلفي. ملفات البروتوتايب الأخرى من المرجع لم تُنسخ،
والصفحات الأخرى لا تحتوي على نصوص أو أقسام.
